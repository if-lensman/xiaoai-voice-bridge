# 开源范围与许可

本仓库公开核心源码、构建安装说明与 APP 功能截图。GitHub Release 另提供 APK、安装工具和两种 NAS 架构的镜像。抖音介绍卡片与文案仅在作者本地整理，不进入源码树或 Release。

公开版本包含源码、通用配置、构建与安装入口、测试及公开文档。内部运维历史、实际设备地址、本机路径、运行日志、备份、语音 Key、设备令牌、签名文件、APK 和模型不进入公开仓库。

自有源码采用 MIT 许可。sherpa-onnx 源码为 Apache-2.0；模型及原生依赖有各自条款，不能视为都由本项目 MIT 许可覆盖。二进制包保留第三方声明与许可文本，见根目录 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。

已确认 LX04 / 2.42.118 上的语音、字幕、触屏控制、自启和 NAS 链路。其他型号、自然抢话的回声消除，以及所有距离与口音下的关键词打断尚未完成验证。

源码已移除过时电脑中转、限时测试、录音探针、过程证据和历史运维材料。保留音箱 APP、中转协议、构建安装工具、必要测试与说明。

公开文档只声明设备权限的前置条件，不展开 root、解锁或刷机的方法。使用须知与免责声明集中在 README，避免将 APP 描述成提权工具或原机恢复方案。
